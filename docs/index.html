Tab Workspace Manager

Replace tab hunting with a dense workspace panel.

Group by domain, open saved workspaces, track chatbot conversations, pin useful pages, and spot tabs playing media without leaving the panel.

  • Native tab groups where the browser exposes them.
  • Popup fallback for Firefox and Safari.
  • Status badges for waiting, responded, pinned, stale, and needs-review LLM tabs.

History Insights

Review browsing patterns without shipping history to a service.

Filter by date and domain, combine history visits with locally cached active-tab time, then export JSON or CSV for analysis.

  • Local storage for active-time aggregates.
  • Date, domain, visit, page, and hourly summaries.
  • Side panel on Chromium browsers, popup fallback elsewhere.
